### 🧐 I. Overview

A walkability score map app that lets you drop a pin anywhere & instantly see how walkable that area is, based on nearby parks, groceries, transit stops, schools, & pedestrian infrastructure sourced from OpenStreetMap. Built to help people quickly gauge whether a neighborhood supports a car-free, walk-friendly lifestyle.
